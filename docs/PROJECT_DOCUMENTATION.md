# Project documentation

## Objective
Create a learning data pipeline to report automotive production, sales, and quality KPIs.

## Stack
Azure Data Factory, ADLS Gen2, Azure Databricks, PySpark, Delta Lake, SQL, Power BI.

## KPI definitions
- Production achievement % = total produced / total target × 100
- Revenue = sum(units sold × unit price)
- Defect rate % = total defective units / total inspected units × 100
